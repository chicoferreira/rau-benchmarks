`backpack.obj` has to sit next to `ssao.sprj`, as it does in the other two projects.

The deviations from the Rau project:

- Extra pass to fix the resolution at 1080p. SHADERed sizes the window pass from its preview panel, and no setting pins it. Every pass of the effect therefore writes to render textures with `fsize="1920,1080"`, and a sixth pass, Present, copies the lit result to the window, which Rau does through egui. Without it the lighting pass would run at the panel's size. Present stretches the image to the panel with no letterboxing, so the preview looks squashed when the panel is not 16:9, but the work measured is the same.
- Two G-buffer passes. A SHADERed pass holds a single shader program, so the room and the backpack cannot share a pass as they do in Rau and Nau3D. Both passes write to the same two render textures. SHADERed skips the color and depth clear when consecutive passes share their targets, so the second pass draws on top of the first.
- Camera. SHADERed's `Projection` system variable is hardcoded to a 45 degree field of view and a far plane of 1000, so `matProjection` is a `MatrixPerspectiveFovLH` function variable instead, with 60 degrees, 16/9, 0.1 and 100, the same as the other two. The view comes from the built-in first person camera, placed at Rau's camera position, with the yaw and pitch (125.537678 and -19.225856 degrees) worked out from Rau's look-at point.
- Gamma. The same as in Nau3D. The window texture is `GL_RGB32F` and `GL_FRAMEBUFFER_SRGB` is never enabled, so `lighting.frag` ends with `pow(colour, 1/2.2)`.
- Room normals. The same as in Nau3D. The built-in cube has real normal attributes, so `room.vert` negates them, where Rau generates the geometry in the shader. Both G-buffer passes start with a render state item that turns culling off, to match Rau's `cull_mode: None`.
- Sample count. SHADERed has no `uint` variable type, so `kernelSize` is an `int` and the SSAO loop counts with an `int`.
- Render texture sampling. SHADERed makes every render texture `GL_LINEAR` with the default `GL_REPEAT` wrap, and the project file cannot change either. Rau's G-buffer sampler is nearest and clamp-to-edge. Lookups with the full-screen quad's texture coordinates land on texel centres anyway, so only the reprojected SSAO samples actually interpolate. The depth attachment is `DEPTH24_STENCIL8` rather than Rau's `depth32Float`, which also cannot be changed.
- V-sync. This is an application setting rather than a project setting, so `launch.sh` runs `configure-shadered.py`, which writes `vsync=0` into SHADERed's `data/settings.ini` and sets the window size before launching it. MSAA and the profiler are off by default and must stay off.
